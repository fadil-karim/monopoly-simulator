The Monopoly AI Simulator is built and released as v1.0 on main, as a Cloudflare Workers static site in this repo.

**What it does**
- Browser-only app with Setup, Play, Games and Analytics tabs. There is no server: API keys stay in your browser's localStorage and every call goes straight from the page to the provider.
- London edition board with the UK Chance and Community Chest cards, plus a Mega edition option: 52 squares (Elephant & Castle, Edgware Road, Downing Street, High Holborn, Aldwych, Shaftesbury Avenue, Savile Row, Knightsbridge, Gas Company, Auction, Bus Ticket and Birthday Gift), the speed die with Mr Monopoly and Bus faces, triples, bus tickets, skyscrapers, train depots, majority-rule building and £2,500 starting cash.
- Full rules: sealed-bid auctions, even building with bank stock limits, mortgages, trades, jail, repairs cards, bankruptcy to a player or to the bank with re-auction, and a round limit with net-worth ranking.
- Players: two to eight, each with a provider (Anthropic, OpenAI, Google Gemini, xAI, Mistral, DeepSeek, Groq, Together, OpenRouter, Cohere, any OpenAI-compatible endpoint, or a free rule-based bot), an editable model id with a Fetch models button, an effort level mapped to each API's reasoning setting, optional temperature, and personal strategy instructions. Universal instructions go to every player.
- Speed: the model is only asked when a decision matters, sealed bids are gathered in parallel, several games run at once, Anthropic calls use prompt caching, and any failed or malformed reply falls back to the rule-based heuristics instantly, so a game never stalls.
- Logs: every game is saved in the browser with its complete event log, per-round net worth and every model call with prompt, reply, latency and token counts. Export one game, all games as JSON or JSONL, or a summary CSV. Analytics aggregates win rate, average rank, net worth, latency, tokens, fallback rate and illegal decisions per player and model, with charts.

**Verified**: the wrangler dry-run deploy passes; 200 headless rule-based games per edition finish with zero illegal actions and the cash and building-stock invariants holding; the real page was driven in headless Chromium through setup, a three-game Mega batch, the saved-games view and analytics at desktop and phone widths with no console errors; and a game was run through the live provider code against a mock OpenAI-compatible server, confirming the effort parameter, cached-token accounting, trade proposals, retries on server errors and heuristic fallback on malformed replies. Screenshots are attached.

**Things to know**
- Rents for the eight extra Mega streets use the price-matched standard rent rows, and the Birthday Gift square pays £100 from the bank. Both are noted in the README.
- A provider that blocks browser requests will show an error on Fetch models; route that model through OpenRouter or a local proxy. Use spend-limited keys.
- The built-in model lists are suggestions. Type any model id or fetch the live list from the provider.
- If the repo is not yet connected in the Cloudflare dashboard, add it under Workers & Pages, Create, Import a repository. A failed build from before this release clears on the next push to main.

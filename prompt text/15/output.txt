The config now holds a pool of models and a number of seats; every game draws that many from the pool at random, never the same model twice, so no model plays against itself, and a pool smaller than the seats plays whole. The default pool has nine models and eight seats, the most the standard board takes, so nine take turns at a table of eight with a different eight each game: Claude Opus 5.5 at xhigh and Gemini 4 Argon direct, GPT-6.1 Sol, Grok 4.7, Kimi K3 and Nemotron 3 Ultra through Perplexity, MiMo-V2.6-Pro, Qwen3.8 Max and DeepSeek V4 Pro through OpenRouter.

The rules the runner applies:

- `seats` in the config or `--seats` on the command line sets the table; the standard board clamps it to eight with a note, and the Mega board takes what you set.
- A model listed twice in the pool is seated once a game, with a note at start; the rules-based bot is not a model and can fill any number of seats, which keeps the test games working.
- The seating order is still shuffled, and a `--seed` makes both the draw and the game repeatable.

To add models, append them to the pool in a copy at `runner/config.json` (or in the default file) and nothing else changes.

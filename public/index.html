API keys

Keys stay in this browser (localStorage) and are sent only to the provider you pick. Calls go straight from your browser to each API, so a provider that blocks browser requests (CORS) will show an error here and that player falls back to the rule-based bot. OpenRouter or a local proxy are the easy workarounds.
